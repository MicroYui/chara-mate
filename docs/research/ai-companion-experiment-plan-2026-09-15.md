## 文本 Pilot 与预算

- 已配置文本 Provider：`localhost proxy / gpt-6-astra`（用户 2026-09-15 明确指定），协议沿用仓库内官方 SDK Adapter。其实际单价不能由 OpenAI 公网同名或近似模型价格代替。
- 首轮 24 个合成情境 × 2 个条件 = 48 次计划生成。失败不会自动重试；协议修正/失败补测最多 16 次，整个首轮最多 64 次请求。
- 每次输出最多 1,024 Token（含推理 Token，若 Provider 计入输出）；因此 Provider 遵守限制时，64 次输出预算上界为 65,536 Token。该限制只用于实验开支，不是产品 Run 停止规则。
- 预计输入 25–45 万 Token；执行前根据冻结 payload 重新估计，使用 Provider 返回 usage 累加，累计达到 50 万时不启动下一请求。单次在途请求会产生一个请求的预算偏差，需在结果中报告。缓存按未命中估算，不预支缓存折扣。
- 费用公式：`inputTokens / 1e6 × P_in + outputTokens / 1e6 × P_out`。若仅作算例取每百万输入 US$3、输出 US$15，则 50 万输入和 65,536 输出约 US$2.49；这些是预算算例单价，**不是当前代理的报价，也不是可保证的金额上限**。代理若按请求计费则另按最多 64 次计费核算。
- 本轮不调用图片、Realtime、Computer Use 或真实外部执行，不做额外模型裁判请求。新一轮及图片/语音验证另给预算。
- 2026-09-15 只读检查发现：通过 CharaMate 已保存凭据请求配置的 `/models` 返回 HTTP 401。当时未进行生成请求。随后按用户要求，使用 Codex 当前已配置的凭据对同一 host 的 `/models` 和 `/v1/models` 验证均为 HTTP 200；此前差异在认证配置，冻结实验采用这条已验证连接。凭据不写入实验产物。

24 个情境在执行前固化为可版本化输入与独立标签：失落只需倾听；明确要建议；支持偏好与当前要求冲突；含蓄而不确定的情绪；表情/窗口弱线索；高兴但结果未明；长期约定回访；半年后旧事；已改口的偏好；当前偏好与旧回忆冲突；普通问候；高频无关记忆；重要但低频承诺；多天同一主题；单次聊天重复噪音；用户纠正误解；需要安静；轻松玩耍；虚构角色与现实事实区分；角色自己的领地经历；行动失败后的真实表达；用户不想管理具体布置；共同工作中的外部噪音；用户接管正在进行的角色活动。

输入文件先冻结 SHA-256、顺序和标签再运行。按情境交替条件顺序，输出盲化为 A/B 后评价。每条标签记录必须遵守的事实与当下支持需求；自然度、可爱程度和愿不愿继续聊分别标注，不能只用关键词命中证明共情。报告配对胜/负/平、每项分子/分母、Wilson 区间、Token、失败、截断和延迟。24 情境只能作先导证据，不能证明长期信任、留存或跨文化普适性；质量近似时保留更简单的基线。

## 离线纵向轨迹

冻结轨迹包含连续活跃、长期离开、短期集中重复、跨日重提、跨 Chat 改口、明确约定、未来事件改期、取消、用户 pin、冷门强相关复活、背景模型反复自述与检索曝光。工作时钟只由真正用户交互推进；后台任务、模型自述、Activity 采样和重复事件重放不得推进。

先做正确性与规模测量，再讨论排序/压缩收益。每个轨迹有独立的预期事实与使用场景，不以候选算法输出生成标签。不能把新记忆保护天数、衰减权重、候选数等启发式包装成脑科学常数。没有纵向真实标签时，只能声明实现了可测的保守估计，不能声明已学会预测未来记忆价值。

单独报告：主动上下文可达性、显式查询可达性、归档/删除语义、长期存储体积。降低默认注入频次不等于删除内容；压缩使用统计不等于压缩事实。活动截图既有清理不能计作本轮长期记忆算法新增收益。

## 来源与版本边界

- 基线 SQLite `better-sqlite3@13.0.1`；[FTS5](https://www.sqlite.org/fts5.html)、[UPSERT](https://www.sqlite.org/lang_upsert.html)、[WAL](https://www.sqlite.org/wal.html)，查阅 2026-09-15。FTS5 的 BM25 数值方向和 SQL 冲突语义是实现依据；单 writer 与同主机 WAL 是边界，不因此引入云数据库。
- [Miller & Cohen 2001](https://www.annualreviews.org/content/journals/10.1146/annurev.neuro.24.1.167)、[ESConv ACL 2021](https://aclanthology.org/2021.acl-long.269/)、[ProactiveBench v1 2026-09-11](https://arxiv.org/abs/2609.12658)，查阅 2026-09-15。脑科学、支持对话和流式主动评测分别提供机制/评价启发，不提供 CharaMate 参数最优性证据。
- 详细记忆与在线来源由同目录研究报告记录；当前第三方仓库 HEAD 必须带完整 SHA，论文机制与当前工业实现分开描述。

## 用户追加的执行约束

单次完整请求输入不得超过 258,000 Token，包含系统、历史、Memory、Tools/schema 和多模态。该约束在实际 Pilot 前已确认；与累计 50 万输入预算分别核算，不允许将一次请求塞满累计预算。固定模型使用 gpt-6-astra。执行前 runner 固定 reasoning.effort=low；manifest 未单列的这一字段应连同归档 runner 复现，结果记录明确披露该记录局限。
