## 结论与产品决定

目前主要可复现错误发生在记忆进入检索器之前：开放情节没有及时形成、同一修订拒绝混合渠道来源、引文定位错误、缺少消歧前文，以及把用户与角色的经历混为一谈。当前修复以实际来源、逐条归属、主材料/前文用途、当前修订和可恢复任务为中心。不能用更大 embedding 或训练编码器来补偿不存在或写错的事实。

冻结 v6 的两个原始开发故事完成 24 个事件、6 个检查点；26 个形成工作中 25 个完成。剩余一个失败是 host 将“新的直接观察”误判为不能补充旧用户报告，已在 v7 单独修正并做零网络原输出复核。该修复不回写 v6 原成绩。

两个真实 Agent 跨 Chat 扩展都正确承接人物关系与改口，但没有调用 memory.search：实际 prepareTurn 已提供充分当前情境。这证明当前情境承接，**不证明冷话题自主搜索、长期检索或记忆采用已经成熟**。继续验收必须区分形成正确、候选可达、选择充分和回答采用四层。

本记录不授权 RRF 60、候选预算 `min(32,000, finalBudget×4)`、一次关系扩展或最终返回条数为成熟默认；它们仍需独立因果比较。也不由本记录宣称自动遗忘、未来价值预测或微调已有质量收益。

## 路径、版本与方法

实际执行 Cognition 分析 → 有来源的断言/闭合 Episode → 原文 resolver → 形成模型 → SQLite revision/source/span → 本地 Qwen3-Embedding-4B-Q4_K_M/512 → exact vector worker、词法/结构召回 → selector。文本模型为 gpt-6-astra，没有改为 gpt-5.6-sol。

来源边界使用冻结作者事件的 fixture，不是私人桌面内容，也不是对真实 Desktop 捕获的验收。来源 ID、内容与时间来自输入，不能用 goldMemory、模型摘要或事后补造原文替代。当前语义处理、索引与生命周期来自实际产品模块；版本 manifest 与每次原始请求在仓库外保留。未读独立 holdout 标签，未把已有开发标签放入模型输入。
