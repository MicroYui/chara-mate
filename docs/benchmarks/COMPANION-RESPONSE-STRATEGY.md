# COMPANION-RESPONSE-STRATEGY：当前需要、克制回忆与角色自主性

日期：2026-09-15。状态：文本 Pilot 完成，采用紧凑策略；生产集成验证见 STATUS。基线 `fc81239304c03648ee3f39ca178f3695ce474ffc`。本次为先导产品选择，不是长期陪伴效果的显著性结论。

## 问题与来源

在同样的人格、历史证据、用户输入和模型下，增加一段回应策略，是否能减少不合时宜的建议、无关回忆和把日常决定反复交回用户，同时保持事实与行动状态真实？前瞻方案见[实验计划](../research/ai-companion-experiment-plan-2026-09-15.md)。

来源核对日为 2026-09-15：[ESConv / ACL 2021](https://aclanthology.org/2021.acl-long.269/)支持把情绪支持过程按当前需要评价；[Miller & Cohen 2001](https://www.annualreviews.org/content/journals/10.1146/annurev.neuro.24.1.167)提供目标对注意/行为的调节类比；[Generative Agents v2](https://arxiv.org/abs/2304.03442v2)提供记忆、反思与自主活动的实现启发。它们都不能证明这段提示词在 CharaMate 上有效，更不意味着需要把每一种支持方式做成独立 Agent。

## 冻结条件与执行

24 个合成情境，每个 baseline/strategy 各生成一次，共 48 次，交替条件先后顺序。baseline 使用基线完整 SHARED_AGENT_INSTRUCTIONS，两个条件均使用同一 Persona、事实和当前消息；strategy 只增加 2,159 UTF-8 字节的陪伴策略。场景涵盖倾听/建议、含糊情绪、半年旧事、改口、问候、过度曝光、低频约定、停止、玩耍、自己的活动、行动失败、用户接管等。没有读取用户真实聊天。

固定模型为用户指定的 `gpt-6-astra`，使用已配置 localhost Provider 的 Responses 协议、官方 SDK `openai@6.49.0`，`reasoning.effort=low`、`max_output_tokens=1024`、`maxRetries=0`、`store=false`、无 Tools。推理档位固定在执行前 runner 中，manifest 未单列此字段；复现需同时使用归档 runner，不能仅凭 manifest 重建所有参数。没有模型裁判额外调用。

两种输出盲化成 A/B，交给当前任务中的独立研究 agent 逐条阅读已有结果；其看不到条件映射。这是单名 agent 的文本盲评，不是真人用户试验，也不是不同模型裁判投票。解盲由 root 在评价文件完成后进行，确定四个获偏好的样本均来自 strategy。评价依据逐项事实、支持需要、自然度、管理负担和记忆使用，保守综合判胜；没有把关键词命中当作共情。

## 结果与分母

| 指标 | baseline | strategy / 对比 |
| --- | --- | --- |
| 完成 | 24/24 | 24/24 |
| 综合配对结果 | 0 胜 | 4 胜、20 平、0 负（共 24 对） |
| 输入 Token | 53,573 | 62,501，增加 16.7% |
| 输出 Token | 1,225 | 1,123 |
| 单次延迟中位数 | 2,955 ms | 2,830 ms |
| 单次延迟最大值 | 8,236 ms | 8,880 ms |

策略获偏好比例为 4/24=16.7%，Wilson 95% 区间 6.7%–35.9%；平局为 20/24=83.3%，区间 64.1%–93.3%；策略落败 0/24，区间 0%–13.8%。这些区间只描述本组样本的比例，场景是人为选择而非用户总体随机抽样，不具有总体留存效果的含义。四个非平局的双侧 sign test 为 p=0.125，不能宣称统计显著。未预注册的该检验仅补充透明度，不替代产品判断。

清晰差异出现在普通问候：baseline 将旧疲惫状态带入问候，strategy 没有。另三组（请求建议、自己的经历、行动失败）主要少了一次让用户补材料或做决定的负担；这些是局部偏好，baseline 并非完全不可接受。盲评未发现明显事实错误或虚构已完成行动，但无实际工具轨迹，不能凭这些文本证明数据库没有错误写入。

全部 48/48 成功，没有自动重试、报错或输出截断。总输入 **116,074**，其中 cached input **107,870**；总输出 **2,348**；最大单次实际输入 **2,624**，远低于用户 258,000 上限。使用了 64 次预算中的 48 次，剩余 16 次未使用。没有 Image、Realtime 或外部行动费用。当前代理单价未知，不把预算算例 US$2.49 称为实付金额。

只有一次生成/条件，没有随机种子重复、真人偏好、跨月追踪或线上 A/B；缓存、交替顺序和代理负载仍影响延迟，因此中位数差不证明速度改进。“可爱”“愿意继续聊”未独立获得可靠量化标签，不能额外报告分数。

## 选择及生产实现

前瞻协议要求质量近似时选简单基线。机械看本组 20 平、显著性不足，不能说实验强制选出胜者。这里记录一个透明的结果后产品取舍：选用 strategy，因为它修正了用户明确在意的一例无关记忆，并在三例减少管理负担；生产仅增加共用提示的四段文字，没有新模型轮次、表、情绪分数或模式切换器。代价是本 Pilot 输入增加 16.7%，收益强度仍需真实体验验证。

生产在 `src/main/agent/agentInstructions.ts` 重新压缩表述，只保留一个版本，Text 与 Voice 共用：

- 先识别此刻需要倾听、安慰、共同处理、轻松交流还是安静陪伴；模糊线索只保留不确定性。
- 回忆服务当前交流；普通问候无需展示画像，旧情绪不当成当前状态。
- 角色可以自主选择小范围虚拟日常，避免反复让用户管理；当前真实需求优先。
- 完成经历以真实 Tool Result 为依据，意图、等待、失败与已完成分开。

生产压缩版并非逐字重放实验的 2,159 字节段落；本 Pilot 支持的是策略方向，不能将其 4/24 原封不动归因于压缩后的最终提示。Runtime、领地应用/取消和 Life 真实结果投影由离线集成另验，不混入该文本评价的分母。
