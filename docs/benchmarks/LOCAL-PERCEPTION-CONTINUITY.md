# 本地连续感知投影：保留原文阅读路径

Decision ID：LOCAL-PERCEPTION-CONTINUITY。2026-09-15，正式360/360检查点与逐事实复核完成。**本次选择维持原文阅读路径，不将P4/P9局部生成投影引入生产。** 原文路径仍有背景细节遗漏，本决定不等于完整桌面理解已通过产品验收；它拒绝的是本次已冻结的额外投影合同与制品，而非否定所有本地感知方法。Root完整审读结果后确认此选择。生产没有引入本候选的第二模型、投影表或模式开关。

## 问题与单一变量

陪伴需要理解持续编辑、浏览和用户改口；把每次桌面正文直接交给 PFC 会占用输入和等待时间。本次比较在原始 Evidence 不变、同一 PFC 与宿主状态机下，增加有原文引用的本地阅读投影，能否提高持续事实质量并减少处理成本。

R 是实际原文阅读视图；P4/P9 只在相同视图编译器中，分别提供 Qwen3.5-4B / Qwen3.5-9B Q4_K_M 生成的局部语义。直接用户消息、Tool、control 不被改写。actual Evidence ID、Persona、actor、时刻、对象、receipt 和 canonical 原文保持不变。局部 unit 不是 observed Evidence、Memory 原文或第二个决策器。

本地输出引用每条当前 primary 的精确 quote，或诚实列为 unrepresented。唯一匹配接受 occurrence=null/0；多匹配须合法零基索引。previousUnitIds 只能引用实际提供的已完成投影。PFC 每条来源只装一次带 UTF-16 offset 的 excerpt，unit 通过 sourceId/spanIndex 指向它；未表示来源保留实际 raw。这个覆盖组装器不是失败后换 R。JSON、来源校验或生成中断失败时，该检查点不调用 PFC，原文继续待处理；不重试、不修补模型输出。

## 评分与解释约束

主指标按故事审查全部检查点所需的持续事实、归属、改口与未完事项；不能用关键词或citation ID命中自动评分。全部检查点人工核对实际 Situation/Intent 与当次Attempt决定；首重复60点由另一位评审另做逐事实 prepared-context 核对，其余 prepared-context 完整保留、统计装入对象并检查关键边界，不冒充所有事实都已做独立的 Agent 输出评审。旧事实的时间限定、superseded或newer observations提示不能被当作每步新错误。空状态没有错误断言，不等于正确理解未知。

独立评审已经对第一重复p01–p05的60点做masked复核，未读路径映射或作者初评；因先前知道部分p01路径，不称完全盲评。原150个事实实例和两个来源受限标签保留。p03:c3“没有自动顺延下周”当时只有用户禁止指令；p05:c1“弟弟实际游戏”当时只有借电脑意向与主页。正确保持未知不记模型错，也不冒充原标签full。最终同时报告冻结原分母和来源可判定的解释性敏感性结果。

当次rationale读懂却未转入Situation/Intent是承接缺口；prepare没有某个非当前人物事实可以是合理焦点选择，不能据此宣称真实Agent用了错误记忆。本次没有实际Agent回答分母。prepare还可能依实际Evidence ID重新装入canonical原文，所以PFC未完整形成某项事实不能直接推导Agent一定用错；来源仍在也不能反向替持久状态评分补分。

直接用户消息虽然不被本地模型改写，但本比较的分析前置阶段失败会令当次 PFC 未执行，连同用户消息一起仍待处理；因此不能称这条候选已经实现生产所需的用户路径故障容忍。raw 继续持久只保证来源还在，不保证及时理解。
