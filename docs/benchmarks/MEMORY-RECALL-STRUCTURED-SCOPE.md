# 记忆召回：时间资格不作为无范围的相关性加分

## 问题与单一实现

当问题只带 `validAt`、`knownAt` 或 `includeSuperseded` 时，原实现额外把用户整个合格记忆库按近时序加入正向召回。这些条件只回答“是否允许使用”，并未提供“为何与当前问题相关”。相机归还记录已存在，词法/向量都能找到，却被这一无范围通道挤出最终候选；扩大答案预算本身不会补回未供应的事实。

选定实现仅在明确实体或事件发生区间 `occurredFrom/occurredTo` 存在时启用结构化正向通道。全部普通词法、向量查询仍执行原有用户/Persona、归档、当前/历史、获知时间和有效时间过滤；准确引用读取合同不变。没有新增模式、参数或回退链。
