## 一手来源与实现边界

2026-09-16 核对 [SQLite WITH](https://www.sqlite.org/lang_with.html)、[limits](https://www.sqlite.org/limits.html)、[EQP](https://www.sqlite.org/eqp.html)、[类型 affinity](https://www.sqlite.org/datatype3.html)。实际运行 better-sqlite3 13.0.1 / SQLite 3.53.3、Node 24.18.0、Apple M4 Pro / 24 GiB。WITH 文档的递归队列及 `AS MATERIALIZED` 能力不意味着任何固定生产深度；limits 页的表达式/trigger 上限不是普通 CTE 行数限制。EQP 只作为当前 SQLite 诊断格式。

当前计划显示，把合法 revisionId 显式投影为 TEXT 后，临时目标关系可同时按 memory_id 与 target_id 连接。开发 r1/r2 的不充分计划和计时保留在仓外；正式只比较 H0 与冻结的最终 H1。此选择没有新增持久索引，也不从开发结果宣称强于其它产品。
