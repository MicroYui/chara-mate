# 连续陪伴独立验收：完成账本与真实缺口

2026-09-16。状态：原冻结批执行和独立复核完成；发现的问题继续修复，商业成熟验收未完成。本文拥有这批独立 holdout 的结果；此前开发结果见[连续场景开发记录](COMPANION-LONGITUDINAL-EVAL.md)。后验修复和已知问题回归单列，不改原输出或分母。

## 产品结论

当前系统能够沿持续情境分清人物、当前改口、历史约定和部分行动边界，但这批实验没有证明可靠的自然冷检索。36 个普通 Agent 首步中，31 个已有相关旧事实，1 个部分有而部分缺失，1 个只需当前结束原话；3 个旧事实未供应的机会全部来自 s07 的认知提交失败。唯一自然 `memory.search` 返回空结果，自然冷召回采用为 0。后台诊断 recall 与形成时的检索都不计作普通 Agent 自主搜索。

真实失败主要落在来源摄入、实体引用、修订合同和完成依据；没有证据支持通过微调 embedding 修复这些问题。本批不改变已选的本地 4B/512 编码器或检索路径。训练只有在事实已形成、查询及候选预算合理时仍反复漏召回，才进入独立选型；不能让更大的编码器承担不存在或写错的记忆。

## 方法、环境与来源

源码为 Main 集成 v3 的 627 文件快照，SHA `bb832d12357aae73845406e2a32508f8310fc9593d3d74496e63bd467be7f6c9`。此处 v3 指最终集成快照，不是旧开发记录中的同名早期形成候选。冻结后未在原运行中修改源码、输入、模型请求或数据库。

原独立素材有 12 故事、144 条事件、36 检查点；按原顺序交替分为两个分区，各 6 故事。运行前通过 48 个离线子进程及 12 条实际 SDK 首请求序列化检查。模型输入只有原事件及真实运行状态，不含标签、期望答案或预制 Memory。两位复核者分别拥有各自六故事的要求，Root 阅读完成后的实际请求、输出、SQL 和复核报告，没有读取原标签或作者生成程序。

每检查点先经真实 Cognition Service、形成服务、SQLite、编码器/向量 Worker 和 selector，保存 SQLite 后再按原用户问句执行独立诊断 recall。普通 Agent 从诊断前的数据库副本创建新 Chat，调用实际 Runtime、prepareTurn 和 Memory Tool，自主决定是否搜索；不强制 `memory.search`，也不注入诊断 Pack。各检查点的 Agent 副本不回投后续 subsystem，因此不能把后续未见上一独立回复解释为生产丢失回执。

这套执行入口接收作者合成的桌面/工具事件，没有执行真实文件、预订或领地操作。部分工具正文写成功而 typed outcome 为 unknown，两者矛盾原样保留。正文匹配原标签不等于实际世界成功，也不能把未知改成失败来消除矛盾。

版本：Node 24.18.0、openai SDK 6.49.0、better-sqlite3 13.0.1 / SQLite 3.53.3；Apple M4 Pro 24 GiB；Qwen3-Embedding-4B Q4_K_M / 512，llama.cpp b10964（b29c606e）。文本模型为 `gpt-6-astra`。编码器及检索主来源版本、模型对照和限制见[本地编码器](LOCAL-MEMORY-ENCODER.md)；认知与脑科学的设计来源见[实施指南](../research/ai-companion-local-implementation-2026-09-15.md)。本批评价当前源码，不从论文名称推断产品质量。

## 后验修复及单一路径

原结果定位后，Main v4 仅增加八个修复文件：四文件[Memory 实体引用合同](MEMORY-ENTITY-REFERENCE.md)与四文件[重访及连续观察时钟](COGNITION-CONTINUOUS-OBSERVATION.md)。其他 619 文件相同。后验同素材运行只覆盖 s03/s05，从空库按原事件重跑，不替换上述 holdout。

已知回归于 18:55:46–19:11:13 UTC 完成，79 次 generation、输入 401,067、输出 38,964、缓存输入 124,771，最大输入 14,595；6 个普通 Run 均 completed / warm、0 自然 search、4 次 record 成功，未见 Provider 或领域拒绝。

- s03 原首条形成实际建立 4 个 Memory 实体和 3 个 Revision；角色实体与 Persona ID 分离。三次 record 均真实成功，其中一次无新增。c09 仍未展开康复细节，c12 新条目未获全部旧指代上下文，不能称统一承诺记忆全部完成。
- s05 e10 实际成为第 10 条来源，12 条全入库；焦点回 Browser 并保存最新观察时钟。PFC 绑定 e10 的 current_foreground，普通 Agent 经当前摘要/带时间的断言回答 1080 对 1100，没有套北京差标。Agent 首步没有再载入 e10 原文；诊断 Pack 仍没选择该新观察，不能把当前情境改善算冷检索成功。

记忆纠正类型、精确错误反馈及独立完成依据的后续包各自留存方案和结果，未完成的包不能从本记录自动晋级。原单次成功或两故事回归不能估计罕见失败率；没有可靠的最终对照说明微调可改善这一批已知问题。
