# CharaMate × 游戏 AI Agent 面试研习

这套材料围绕你给出的米哈游 Agent 岗位要求，以 CharaMate 的代码、实验和失败记录为基础，准备项目深挖与咖啡馆 NPC 系统设计。资料核对日期补充至 2026-10-30；当前文档基线为 `9df3c06a377868062a79d2272c99087bfcae79c7`，`src/` 与前轮 `8e50d50f47fd961fbed9174d76f145a5e22b58d1` 无差异。第 03、04 章展开连续执行与记忆形成，第 15、16 章回答此前两轮追问；第 17–19 章回应一面后的六问。

**准备二面的项目故事，先读 [20 四条优化故事](20-four-optimization-stories.md)。** 它把记忆、语音、认知注意与主动陪伴各写成一条可口述的因果叙事，再展开源码、真实失败、实验取舍和未完成部分的具体方案。酒会的“超类脑”概念作为你提供的契机；“陪伴又不打扰”是你自己的问题，不归因于对方回答；语音版本已确认是 `gpt-realtime-2.1`。

本版按整套材料统一加深：从输入与数据结构讲到执行、并发和恢复，再解释方案怎样比较、结果说明什么、为什么采用或放弃。已有实验给原始分母与限制；数据飞轮和游戏服务端等未建设能力给实施与验证方案。正文中的代码标识用于查找，普通叙述按完整中文解释其含义。

系统学习整套材料时，从 [SDD 大纲与学习安排](00-study-spec.md) 开始。工程单元沿源码与实验记录学习；研究单元由正文直接讲解论文和工业实践，不要求另读原文。每个单元都留下图、表、口述或实验卡，再闭卷处理变式。个人是否掌握，按 [15 项验收任务](12-mastery-acceptance.md) 判断，初始状态均为未执行。

## 四条贯穿全套材料的主线

**执行主线：**输入 → 任务状态 → 模型与工具 → 效果回执 → 后续决策 → 用户可见结果。重点不是循环写得多复杂，而是每一步能否取消、恢复和解释。

**认知与记忆主线：**观察 → 有来源的判断与目标 → 长期形成 → 修订和索引 → 检索与最终供给 → 行动资格。用户纠正会穿过整条链，不能只改向量库。

**研究主线：**实际失败 → 排除错误原因 → 最小基线与候选 → 公平比较 → 结果与代价 → 保留单一实现。要能解释未选方案，而不只是介绍最终配置。

**游戏迁移主线：**玩家进店 → 有限感知 → 是否值得判断 → 记忆与当前状态 → 合法动作提议 → 权威提交与发言仲裁 → 实际曝光 → 新经历和评测。咖啡馆设计沿用可迁移原则，同时补齐多人世界的边界。

## 使用时保持证据口径

当前实现、历史实验、拟建方案和外部研究在各章分别说明。历史测试没有在此次文档工作中重跑；教学数值不属于实测；咖啡馆是面试设计方案，不代表星布谷地或米哈游内部架构。

酒会交流可以作为你真实的研究动机。个人职责、代码贡献和实验参与按实际经历补充，不能把仓库全部成果直接写成自己的业绩。最终准备目标是能够根据证据解释与取舍，而不是背出最漂亮的百分比。
